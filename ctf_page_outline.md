# CTF Page Outline

Site appearance

- The site title should be "PANW Capture the Flags" and include "assets/images/PAN-Color.png" as the icon image.
- The site should us the color scheme and fonts in this web page: "https://www.paloaltonetworks.com/prisma/prisma-ai-runtime-security"

This capture the flag page should consist of the following pages: 

1. Registration page
2. Self-guided demo and Capture the flag menu that lists all available Demos and Capture the flags
3. Self-guided demo prior to the CTF which will contain the necessary CTF companion and link to the quiz
4. The actual capture the flag



## Registration page

- The participant will register with their Name and Email. 
- There should be a note that tells the participant to use the Email they used during the sign up process.
- The page will reference a Google Sheet that is pre-populated with a list of Names and Emails.
